# Methodology

This migration preserves the focused OpenAI and Anthropic refresh from the source package without re-scraping or altering its values. It contains 212 flattened price records. The source package reports ten official-source captures and keeps publication authorization false.

## Population and variables

The population is the nine offerings included by the source refresh. Rows distinguish provider, model, region, service tier, billing mode, price component, context boundary, amount, unit, observation time, and source identifiers.

## Exclusions and uncertainty

This is not a complete market census. Prices, tiers, region availability, model names, and tokenization can change. The package does not independently establish that the captured source set is complete, that redistribution is permitted, or that the proposed license is approved.

## Reproduction

Use the distributed CSV or JSON with the included schema. The provider-count chart groups CSV rows by normalized provider identifier; exact plotted values appear in its companion CSV.
